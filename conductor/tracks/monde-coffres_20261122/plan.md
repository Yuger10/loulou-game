# Plan : 🗝️ L'Île des Coffres

Spec : [spec.md](spec.md)

Quatre PR, **chacune livrable seule** (chaque merge est en production une minute après) : 1a et 1b (« Le trésor raconté », découpé en deux), 2 (« Le code secret »), 3 (l'île). 1a précède 1b ; 2 peut passer avant, entre ou après elles. Les phases 1a et 2 ajoutent chacune un mini-jeu proposé dans « choisir un jeu » sur toutes les îles. La phase 3 attend que la track `saison3-ouverture` soit sur `main`, avec ses six fichiers `-s3` préparés vides (`characters-s3.js`, `characters-art-s3.js`, `squishies-s3.js`, `squishy-art-s3.js`, `story-s3.js`, `island-s3.js`), et que l'île précédente, `dumplings`, soit dans `WORLDS` (ordre des îles : crayons, dumplings, coffres, chatouilles, concert). Le passage des tests de carte à 3 onglets se fait dans la track Crayons, pas ici. Chaque PR se termine par un rebase sur `main`, `bun run check` vert, la commande de livraison (numéro pris sur `main` après rebase, jamais fixé à l'avance) et la section du PRD : `bun run release patch "résumé"` pour les PR intermédiaires (1a, 1b, 2), `bun run release track "résumé"` pour la dernière (3).
