# 🌊 Le Lagon Magique

Petit jeu mobile-first en un seul fichier HTML/CSS/JS pour une enfant de 6 ans : aider une sirène, une licorne et une danseuse via des mini-jeux, gagner des objets, puis les vendre, échanger, acheter ou fusionner au marché.

## Lancer
Ouvrir `lagon-magique.html` dans un navigateur (ou servir le dossier : `python3 -m http.server`).
La sauvegarde utilise `localStorage` — elle persiste sur le même navigateur.

## Fichiers
- `lagon-magique.html` — le jeu complet
- `PRD-lagon-magique.md` — cadrage v1 et améliorations v2
